# ahVanguard email assets

Public static host for images used in marketing email, served over GitHub Pages.

Why: SiteGround's anti-bot (SGCaptcha) answers image requests from Outlook and
Gmail image proxies with an HTML challenge page instead of the file, so every
image hosted on velscope.com, hq.husknet.com or hq.ahvanguard.com renders broken
in those clients. GitHub Pages serves the bytes to anyone.

- `velscope/` - the standard VELscope email footer assets (`ahv_velscope_footer()`)
- `webinar-p2/` - Oral Cancer Screening Series part 2, Sep 29 2026

Nothing here is secret. Do not put anything here that is.
